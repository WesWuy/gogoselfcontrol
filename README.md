# gogoselfcontrol.org

> Help men who need their men to find their men.

A directory of men's gatherings — circles, ministries, recovery rooms, mentorships, hiking collectives, therapeutic groups, civic and faith fraternals.

## What's in this repo

Static HTML/CSS/JS site, hand-coded, no build step. Deployed to GitHub Pages from the `main` branch root.

- `index.html` — Home page
- `directory.html` — Filterable directory of all 351 listed organizations
- `about.html` — About the project
- `disclaimer.html` — Cold-listing notice, crisis hotlines, ethical framing
- `directory.json` — Structured data (also embedded in `directory.html` so the page works from disk without a server)

## Status

All 351 entries are currently `cold-listed` — researched but **not personally verified**. URLs may be stale, programs may have changed, organizations may have moved or closed. Treat every entry as a starting point for your own due diligence. Read [the disclaimer](disclaimer.html) before relying on any listing.

## Local preview

Open `index.html` directly in a browser. No server required; data is embedded in `directory.html`.

## Crisis resources

If you are in immediate danger to yourself or another person, please contact a crisis service directly:

- **United States** — 988 Suicide and Crisis Lifeline (call or text 988)
- **Canada** — 9-8-8 Suicide Crisis Helpline (call or text 988)
- **United Kingdom** — Samaritans 116 123 / CALM 0800 58 58 58
- **Ireland** — Samaritans 116 123 / Pieta 1800 247 247
- **Australia** — Lifeline 13 11 14 / MensLine 1300 78 99 78
- **New Zealand** — Lifeline 0800 543 354 / 1737 (Need to Talk)

## Removing or correcting an entry

If you represent an organization listed here and want the entry removed, corrected, or updated, please open an issue on this repo. Reasonable removal requests are honored without dispute.
